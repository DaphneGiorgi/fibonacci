# fibonacci

Une application C++ qui calcule les nombres de fibonacci.

## Prérequis
- g++ ≥ 14.2

## Compilation
```bash
mkdir build
cd build
g++ -I../include ../src/main ../src/fib.cpp -o fib.exe
```

## Exécution
```bash
./build/fib.exe 
```

## Structure du projet
```text
MyProject/
├─ README.md
├─ include/
│  └─ fib.hpp
└─ src/
   ├─ main.cpp
   └─ fib.cpp
```
